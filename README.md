GravityBox
==========

Fork notes: Compiled for running on Android 16 (API 36)
XPosed Tweak Box for devices running Android 16 (API 36)

Revival status
--------------

This abandoned project has been rejuvenated with vibe coding and brought back
to a state where it builds and starts on modern Android with Vector.

This is still a work in progress. Every GravityBox feature and framework hook
needs to be re-validated against current Android internals. Expect individual
features to be incomplete or broken until that work is finished.

Visit the [official support thread](https://forum.xda-developers.com/t/app-r-xposed-gravitybox-v11-0-5-for-android-11-08-08-2021.4213047/page-29#post-87075427) at XDA for more info.
